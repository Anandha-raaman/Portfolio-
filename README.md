# Anandha Raaman S — Generative AI Engineer Portfolio

A modern, high-performance portfolio website showcasing production LLM orchestration, autonomous multi-agent state machines, hybrid RAG pipelines, and full-stack AI engineering.

## 🚀 Key Highlights & Stack

- **Core Specialization**: Generative AI Engineering & Multi-Agent Systems
- **Agent Orchestration**: LangGraph, LangChain, Supervisor-Worker Routing, Human-in-the-Loop (HITL), Pydantic
- **RAG & Search**: Dense + Sparse BM25 Hybrid Retrieval, FlashRank Cross-Encoder Reranking, ChromaDB, FAISS
- **Backend & Data**: Python, FastAPI, Flask, SQL, PostgreSQL, SQLite, Streamlit, Pandas
- **Design System**: Vanilla CSS with custom properties, Glassmorphism, Dark/Light theme toggle, fully responsive

## 💻 Local Preview

1. Open this folder in VS Code or any editor.
2. Double-click or open `index.html` directly in your browser.
3. Or use the Live Server extension (`Right-click index.html -> Open with Live Server`) or run:
   ```bash
   npx serve .
   ```

## 🌐 Deploy to GitHub Pages

1. Initialize git (if not already):
   ```bash
   git init
   git add .
   git commit -m "feat: complete professional portfolio upgrade"
   ```
2. Push to your repository: `https://github.com/Anandha-raaman/Portfolio-`
3. Go to **Settings** → **Pages** in GitHub.
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your portfolio will be live at `https://Anandha-raaman.github.io/Portfolio-`.
